# 🐍 freeCodeCamp Python Certification Projects

A collection of the five core Python projects built to complete the **freeCodeCamp Python Certification**, demonstrating proficiency in object-oriented programming, data structures, and algorithmic problem-solving.

## 📂 Projects Included

1. **[User Configuration Manager](./01-user-configuration-manager)**
   * **Concepts:** Dictionaries, sets, key-value manipulation, and state validation.
   * **Description:** A utility system to manage, update, and validate user settings cleanly.

2. **[Budget App](./02-budget-app)**
   * **Concepts:** Classes, methods, string formatting, and encapsulation.
   * **Description:** A `Category` class ledger that tracks deposits, withdrawals, transfers, and generates an ASCII spending chart.

3. **[Polygon Area Calculator](./03-polygon-area-calculator)**
   * **Concepts:** Object-Oriented Programming (OOP), inheritance, and method overriding.
   * **Description:** Implements `Rectangle` and `Square` classes to calculate geometric properties and render ASCII shape representations.

4. **[Hash Table](./04-hash-table)**
   * **Concepts:** Linear data structures, hashing algorithms, and collision handling.
   * **Description:** A custom implementation of a hash table supporting insertion, lookup, and deletion operations.

5. **[Tower of Hanoi Algorithm](./05-tower-of-hanoi)**
   * **Concepts:** Recursion, state tracking, and algorithmic optimization.
   * **Description:** Solves the classic mathematical puzzle recursively for *n* disks while logging every move.

## 🛠️ Tech Stack & Concepts Covered
* **Language:** Python 3
* **Core Skills:** Object-Oriented Programming (OOP), Custom Data Structures (Hash Tables, Graphs, Trees), Recursion, Dynamic Programming, and Error Handling.
